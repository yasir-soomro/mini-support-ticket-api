

# Delegation Contract

## Outcome
Produce a working Support Ticket API that satisfies the specification.

## Context
- Python
- FastAPI
- Pydantic
- pytest
- Read `docs/specification.md` before implementation.

## Constraints
- Do not add authentication.
- Do not add a database.
- Do not add features not present in the specification.
- Keep the implementation simple and understandable.

## Authority

### AI may
- Create project files.
- Write implementation code.
- Write tests.
- Run the application.
- Run tests.
- Fix implementation bugs.

### Human retains
- Final requirements.
- Business-rule decisions.
- Scope changes.
- Architecture approval.
- Final acceptance.

## Deliverables
- Working FastAPI application.
- Automated tests.
- README.
- Test results.

## Verification
The work is acceptable only when:
- All specified endpoints work.
- Business rules are enforced.
- Tests pass.
- No unauthorized features were added.
- Actual test results are reported.
